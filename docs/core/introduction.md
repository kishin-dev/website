# Kishin Core

Kishin Core is an all-in-one **Skyblock core for Paper 1.21**. It's the plugin behind Kishin Skyblock, and it replaces the fifteen to twenty separate plugins a Skyblock server usually needs - so every feature shares one database, one design and one config style.

> **Status:** in development. These docs follow the current build and are generated partly from the plugin itself, so the command, permission and config pages are always up to date.

## What's inside

| Area | Features |
|---|---|
| **Islands** | Creation from schematics, members, coops, warps, bans, bank, upgrades, levels & worth, missions, visiting & ratings, weekly top rewards, nether & end |
| **Automation** | Six minion types, fuel-based generators, chunk collectors, harvesters, block / spawner / mob stacking |
| **Pets** | 16 yokai pets in 5 rarities, summon slots per rank, upgrades, merging, disposal, pet eggs with a hatching animation |
| **Combat & events** | World bosses with phases and special attacks, server events, combat tagging, classes |
| **Progression** | Skills, collections, custom enchants, player levels, prestige, leaderboards |
| **Rewards** | Crates, lootboxes, daily rewards, challenges, a 100-level battlepass, first-join tutorial |
| **Economy** | Shop & sell, gem shop, auction house, buy orders, safe trading, sell wands, fishing |
| **Store** | An in-game `/buy` menu: credit packs (via Tebex), ranks, a monthly rank, crate keys, the battlepass |
| **Presentation** | Animated scoreboard and tab list, holograms, NPCs, chat games, announcements |
| **Server basics** | Built-in ranks & permissions, moderation, homes, teleport requests, messaging, essentials |

Every feature is configured in its own file in `plugins/Kishin/`, all text is [MiniMessage](https://docs.advntr.dev/minimessage/format.html), and most changes apply with `/kishin reload`.
